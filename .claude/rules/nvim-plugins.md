# Neovimプラグインファイルのルール

このファイルを作成・編集する際は、必ず1行目に機能説明コメントを追加してください。

## 形式
`-- [機能の簡潔な説明]`

## 例
- `-- カラースキーム`
- `-- ファイルエクスプローラー`
- `-- Git変更箇所の表示`
- `-- ターミナル表示`

## lazyconfig.lua への登録

プラグインファイルを新規作成した場合は、必ず `nvim/lua/lazyconfig.lua` の `spec` 配列に以下の形式で追加してください：

```lua
{ import = "plugins.<プラグイン名>" },
```
