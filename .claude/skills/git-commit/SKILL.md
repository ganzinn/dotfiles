# git-commit

変更内容を分析し、日本語の簡潔なコミットメッセージでコミットを作成する。

## 手順

1. `git status` で未追跡・変更ファイルを確認する（`-uall` フラグは使わない）
2. `git diff --staged` でステージ済みの変更を確認する
3. ステージ済みの変更がある場合:
   - その差分のみを対象にコミットメッセージを生成し、`git commit` を実行する
   - **未ステージの変更には一切触れず、ここで終了する**
4. ステージ済みの変更がない場合:
   - `git diff` で未ステージの変更内容を確認する
   - 変更内容を分析し、コミットメッセージを生成する
   - 関連ファイルを `git add` で個別にステージングする（`git add -A` や `git add .` は使わない）
   - `git commit` を実行する
5. `git status` で結果を確認する

## コミットメッセージの規則

- 日本語で簡潔に記述する
- HEREDOCで渡す:
  ```
  git commit -m "$(cat <<'EOF'
  コミットメッセージ
  EOF
  )"
  ```

## 注意事項

- `.env` 等の機密ファイルはコミットしない。機密ファイルが含まれる場合はユーザーに警告する
- 変更がない場合は空コミットを作成しない
